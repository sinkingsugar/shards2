## F1 — P1 Push Clear invalidates a sequence initialized in Once
- Location: crates/shards-core/src/stackless/runtime.rs:344 and the corresponding stackful iteration reset
- Evidence: the following checked successfully but logged 1 then failed at Count with a type mismatch on the next iteration. The iteration reset replaced the sequence with None while Once prevented reinitialization.

```shards
@wire(w {
  Once({1 >> s})
  s | Count | Log
} Looped: true)
@mesh(m)
@schedule(m w)
@run(m Iterations: 3)
```

- Impact: a valid composed variable becomes invalid across iterations, on both schedulers.
- Suggested direction: preserve valid sequence state and align clearing with the declaring Push execution.
