## F1 — P2 `inline::run` borrows the previous output for the whole segment, so later Push/Set calls copy captured collections
- Location: `crates/shards-core/src/flow.rs:63` and `crates/shards-core/src/stackless/mod.rs:313` pass `&value`. `crates/shards-core/src/inline.rs` `run(…, input: &Var, …)` keeps that borrow until the segment ends.
- Evidence: in the generic path, each shard's output replaces `value`, so the previous output is dropped before the next shard runs. An inline segment instead keeps its input alive until it returns, even after the accumulator has moved to a constant or a slot. If that input shares a collection that a later `Push` in the same segment mutates, `Arc::make_mut` copies the whole collection on every iteration:

  ```
  [] >= acc
  Repeat({
    [acc]
    1 | Push(acc Clear: false)
  } Times: 40000)
  acc | Count
  ```

  Measured (stackless / stackful): 98a75c6 9 / 7 ms; 7c974be 2600 / 2593 ms; a003cb7 2604 / 2577 ms. `{a: acc}` behaves the same (8 / 8 ms, then about 2.6 s at both later commits). Adding a fallback shard between them (`[acc] | Count`) restores linear time at a003cb7, which isolates the segment-input borrow as the cause. All runs printed `40000`.
- Impact: any non-inline shard whose output shares a collection that a following inline segment grows or replaces turns a linear loop into a quadratic one, compared with 98a75c6. A large input also stays alive longer than before. The results are unchanged.
- Suggested direction: pass the segment input by value, and drop it as soon as the accumulator stops pointing at it (at the first Const/Get/Take/arithmetic result), or at least before any instruction that writes a frame slot. Add a shared-suite owner-count regression like the `discarded_*_constructor_*` tests, with the constructor followed directly by `Const` and `Push` and a pause, checking the captured value's count.
- Not covered: the pre-existing passthrough case (`acc | ExpectSeq` then Push) is already quadratic at 98a75c6 (see the notes in the earlier review). This finding covers only the regression the inline segment introduced.
