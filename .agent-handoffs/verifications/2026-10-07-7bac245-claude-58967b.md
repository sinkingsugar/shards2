## Scope for the reviewer

The contract is `docs/golden-path.md` (§3 to §7, §10 tests A to M, §11 reload policy); `docs/current-state.md` has the per-milestone status, the M5/M6 notes, the device findings and the deviations. Suggested focus, in order of risk:

2. `crates/shards-core/src/stackless/engine.rs`, the function frames (`Frame.invocation`, `switch_scope` and its documented contract, `enter_kept_frame`, `reset_invocation`/`revive_invocation`), `migrate_component`, the call-depth limit and cleanup on `recursion-limit`.
3. `crates/shards-core/src/compose.rs`: `Owner::{Wire, Function}` scope rules, `compose_call`, the compose cache keyed on (definition, input type), two-pass recursive groups, `lazy_refs`, purity and mesh-access checks, `vm_only`/`vm_leaf`/`scratch_slots`/`native_state` on `CompiledFunction`.
4. `crates/shards-core/src/reload.rs` and `stackless/runtime.rs`: admission, `keep_plan`, `same_body`, `validate_reload` against live bodies, `ResetPolicy`.
5. `crates/shards-core/src/var.rs`, `types.rs`, `shards/data.rs`: the 32-byte `Var`, `Table` representations and `Shape` interning, `Op::TakeSlot`, the in-place `TableMake` and `SeqMake` constructors, `Type::admits` by shape handle.
6. `crates/shards-lang/src/lower.rs`, `program.rs`, `session.rs`: `@fn` lowering, `CheckReport.functions`, non-generic `Session`, `reload_preserving` on functions.

Deliberate choices worth challenging: a stateful callee's non-Keep locals are cleared between invocations; `input: None` means "ignores input"; caller bodies keep their compiled code when only a callee changed; host-built map tables are not converted to struct tables at the mesh boundary; `Float2` is f32; a VM loop or branch refuses to start unless every site inside is ready (so the first call through a loop body and the first call after a reload take the frame path for that iteration); a child flow with a constructor is entered as a frame rather than run in dispatch; the dispatch match is out of line (measured).
