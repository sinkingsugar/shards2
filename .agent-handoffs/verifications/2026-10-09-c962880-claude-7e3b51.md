## What changed and where to look

M8 of [docs/metaprogramming.md](../../docs/metaprogramming.md): `#( )` and `@const`, stopped at the §2.4 gate for review; M9 starts only after it. §2.5 there describes the implementation. The decisions folded into §1 to §4 (audited safe list, budgets, one `compose-time-cycle` class, only successes cached, exact literal type, no `$0`/`$1`/`$i` port) are the author's and are not open for review here; the implementation of them is. Suggested focus, in order of risk:

1. Metering and the memory bound, `crates/shards-core/src/compose_time.rs` (`Meter`, `SAFE`, `eligible`, `text_size`, `VALUE_DEPTH`) and its call sites: `inline.rs` (`VmCalls::METERED`, `Metered`, `meter_push`, `construct`'s meter), `stackless/engine.rs` (a unit per step that starts work, `note_depth` at entry), `shards/data.rs` and `shards/values.rs` (`PureOp::meter`). Claim to break: every allocation an evaluation can make is charged a unit per byte before it happens, so fuel bounds total allocation, and nesting is bounded at 64 levels, so dropping a value cannot overflow the stack. A self-push loop (`s | Push(s)`) overflowed the stack before `Meter::nest`; look for other shapes. Check also that each shard on `SAFE` charges in proportion to its work.
2. Eligibility, `compose/evaluate.rs::not_compose_time` and `Analysis::not_compose_time` in `signature.rs`/`compose.rs`: effects, then lifetime, then mesh access, then a native shard off the list, innermost occurrence chosen, carried by cached function bodies. A path into the host or the mesh from `#( )` that is not refused would be P1.
3. The cache, `compose/evaluate.rs::evaluate`/`record_evaluation` and `Dep::Evaluation` in `reload.rs`: a hit needs valid deps and usage that fits the requester's `EvalLimits`; reached functions become `Dep::Inlined`; `Dep::Evaluation` restarts on reload. Check stale results after an edit and hits under smaller limits.
4. The isolated run, `compose/evaluate.rs::run`: a temporary engine with no mesh, `InstanceId::MAX`, a noop waker, `catch_unwind`; `recursion-limit` maps to `expansion-budget`, everything else to `compose-time-error`.
5. Lowering, `crates/shards-lang/src/lower.rs`: `@const` pre-pass and cycle detection, `constant`/`constant_pipe` (literals holding an evaluation become one `Seq.Make`/`Table.Make` evaluation), Match cases and defaults rejecting `#( )`, `not-a-macro`; `lexer.rs` `$<digit>` (`implicit-loop-variable`).

Deliberate choices worth challenging: the default limits (native fuel 10M, depth 256, value 1 MiB, output 64 KiB; ESP-IDF 20,000 / 32 / 4 KiB / 2 KiB); `Maybe`, `Stop`, `Return` and `Log` off the safe list; a unit per 16 bytes read through by comparisons and formatting; `@const` lowered at each read rather than once; cache entries never evicted, like the rest of the compose cache.

Open, for the author: a `compose-time-error` path ends at the `#( )` (the message names the failing shard). Pointing at the shard needs runtime errors to carry the failing node's occurrence path, which the engine does not record.
